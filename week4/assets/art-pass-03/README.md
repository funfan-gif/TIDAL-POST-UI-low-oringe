# Art Pass 03 · 地点插画资产

本轮全部为原创、独立、可编辑的 SVG，没有使用 ImageGen，没有整张 UI 或地图背景替代交互。

| 文件 | 用途 |
| --- | --- |
| old-post-harbor.svg | 内凹港湾、钟楼邮局、渔屋、邮件棚、稀疏植被与近岸水色 |
| postal-harbor.svg | 旧港木码头、系缆柱与绳索，位于固定玩家船下方 |
| blue-tide-island.svg | 北凹湾、独立海岸、沙岸／鼠尾草／苔绿颜料层、邮務小屋、4 组树冠 |
| north-pier.svg | 连接原目的地坐标的栈桥、小泊位、邮旗与系缆柱 |
| fog-reef-shoal.svg | 不规则沙绿浅滩、3 组露礁、2 块水下礁、碎浪、3 条薄雾与水深 |
| fog-reef-danger.svg | 危险时的少量珊瑚色岩缘和加强碎浪，透明叠加 |
| white-lantern-lighthouse.svg | 白塔、暖橙塔顶、淡岩岸与静态金色引导线 |
| north-buoy.svg | 低权重浮标杆、灯旗与水线，两处复用 |
| old-wreck-shoal.svg | 不规则浅水沙洲、半沉木架、断桅与碎浪 |

所有图像透明背景、无 UI 文案。雾礁资产内只包含 `4 m` / `5 m` 水深；地名、坐标、警告、船只与目的地图标继续由主 SVG 独立渲染。

手工 path 决定形体；局部滤镜只用于颜料底层，没有全场景模糊或动画。建筑分别采用钟楼长厅、高窄渔屋、低斜顶棚和宽檐小屋四种轮廓。

主 SVG 的逻辑障碍仍使用原数据，放在透明代理组中。视觉地物均 `pointer-events: none`，在路线与航点之前绘制。危险斜线由主 SVG 的自然浅滩 path 提供，使用原有 `.is-danger` 状态绑定。

Art Pass 02 的海域纸纹和其他资产原样保留；其历史 ImageGen 来源见上一轮资产目录说明。
