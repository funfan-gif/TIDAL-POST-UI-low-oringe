# Art Pass 02 可组合美术资产

| 文件 | 来源 | 页面用途 |
| --- | --- | --- |
| `sea-paper.png` | Codex 内置 Image Generation 生成，1536 × 1024 | 空白水彩海域纸纹；不含岛屿、路线、文字或 UI |
| `cabin-surface.svg` | 本轮原创 SVG | 克制的海玻璃船舱 / 木桌底面，纤维、盐粒与暗角 |
| `land-pigment.svg` | 本轮原创透明 SVG | 苔绿、鼠尾草与浅赭颜料晕染；裁切进原有海岸 |
| `ledger-paper.svg` | 本轮原创 SVG | 邮务记录纸、浅横线、折痕、穿孔 |
| `dispatch-frame.svg` | 本轮原创 SVG | 不规则双描边纸质放行按钮框 |

海域资产生成 brief（归纳记录）：单独的空白邮务海图纸张，温暖象牙色毛边与淡海玻璃水彩，纤维、少量盐斑和折痕；中心保持浅淡可读；无地理、文字、图标、路线或 UI。使用不透明背景，因其是纸张底材。

原计划另生成岛屿颜料图，工具返回网络错误，没有获得或引用该资产。最终使用原创 `land-pigment.svg`，保持透明、独立、可编辑。没有将生成的整张 UI 截图当作页面背景，也没有复制参考游戏素材。

地图内树、港湾、房屋、灯塔、浮标、礁石、罗盘、纸签、危险三角与锁均为本项目可编辑 SVG；原 V3 的返回、海图和帆船 PNG 保持原路径与内容。

字体：标题、地名、少量注释使用本机系统 KaiTi，后备 STKaiti / SimSun；操作正文使用原有 Microsoft YaHei 等清晰 UI 字体；坐标与数值使用 Georgia / Times New Roman。未下载、复制或分发第三方字体文件；跨系统会按后备字体显示。

使用方式：`index.html` 分层组合底材、地理、网格、危险区、航线和交互；海岸裁切路径复制自原碰撞路径，未改变原碰撞形状。PNG 约 2.9 MB，属于本地离线资产。
