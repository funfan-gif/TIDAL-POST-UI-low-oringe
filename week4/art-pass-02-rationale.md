# TIDAL POST WEEK 4 — ART PASS 02

本轮基于已完成的 Function Pass，在 `week4-route-chart` 分支上深化美术。任务流程、信息架构、地图尺度和固定委托不变。

## 改造前的主要问题

1. 海面是平整色带与规整向量形状，缺少潮气、颜料浓淡和纸纤维。
2. 航点与目的地标签偏圆角网页控件，难以让人联想到邮差手中的海图。
3. 右侧规则分隔、状态盒与实色主按钮仍有网页侧栏感。
4. 普通背景与默认标题字体使地图像页面内容，邮务身份主要依靠名称与既有图标。

修改前已在真实 Edge 浏览器查看 1920 × 1080 两种状态，保留 `00-before-valid.png` 与 `00-before-blocked.png`，完整审查见 `qa/art-pass-02/art-audit.md`。

## Visual thesis

一名海上邮差在旧邮船船舱中，摊开留下潮痕与盐粒的邮务海图，用墨线、图钉、地址纸签与放行邮戳规划通往蓝潮岛的安全路线。

海玻璃底面托住浅色地图，海图约占视口宽度 73%。水彩与纸材形成游戏道具的存在感；最深的墨色留给路线、起终点、状态和操作。网格、水深、罗盘、纸纹维持第三层信息。邮务身份集中在目的地地址签、TP-042 记录纸、圆邮戳与放行反馈四处。

## 美术如何支持规划

| 美术变化 | 规划作用 |
| --- | --- |
| 浅海域底材 + 较深路线墨迹 | 让玩家先追踪当前位置 → W1 → W2 → 北侧码头 |
| 不规则地址纸签、码头连线与信封目标 | 起点与固定交付目标容易找到，不增加目的地选择 |
| 图钉、墨圈和小纸签 | 明确 W1 / W2 是可调整输入；保留原命中范围 |
| 方向箭头 / 危险交叉标记 | 将行进方向与失效航段直接放回地图；避免覆盖数值纸签 |
| 虚线、斜线、三角、原因与锁定 | 灰度下也能判断危险，不仅依靠珊瑚红 |
| 窄邮务记录纸和纸质放行框 | 记录对应同一航线，确认像本次邮务的放行操作 |
| 190ms 许可盖章反馈 | 确认结果清楚且短促；减少动态效果设置下关闭动画 |

## 真实限制

目标仍是 1920 × 1080 PC 界面，其他比例使用整场景缩放与留边。50% 时核心路线、状态与操作可识别，但小坐标与水深适合放大阅读。KaiTi 是系统字体，跨系统显示存在差异。

3 秒层级检查是截图审阅自查，没有招募真实玩家，不能视为正式用户测试。潮汐仍固定于 06:40，坐标与水深为虚构数据；V3 航行尚未读取新路线。本轮不增加这些功能。
