检查基于 Microsoft Edge 的真实 1920 × 1080 渲染与自动截图，2026-10-04。

| 要求 | 证据与结果 |
| --- | --- |
| A. 布局 | 两状态人工查看；海图、记录、确认与标题均位于视口内。记录文字无溢出，重置和页脚均留在纸面内。 |
| B. 第一眼 | 左下“当前位置”、右上“固定目的地”、连续航线、右侧状态与确认建立清楚视觉层次。属于设计者启发式检查，尚无真实玩家三秒测试。 |
| C. 50% | `06-blocked-half-scale-960x540.png` 中航点、危险三角和主要标签可辨认；缩放后真实拖拽仍有效。小字号坐标和说明需要全尺寸阅读。 |
| D. 灰度 | `04-blocked-grayscale-1920x1080.png` 与 `05-valid-grayscale-1920x1080.png` 中仍可通过实线/虚线、斜线、三角、状态文字及锁定按钮区分状态。 |
| E. 交互 | 自动 QA 使用真实鼠标移动和按键，检查 W1/W2、航向/航程同步、Hover、键盘与重置。 |
| F. 失败恢复 | W1/W2 进入雾礁、沉船礁及陆地均被阻止；两端在危险区外但航段穿越也会阻止。恢复后确认启用。 |
| G. 延续性 | 继承 V3 色彩、邮务纸本与原图标。地图从系统直线变为可编辑的三段航线，旧 V3 文件保持不变。 |

视觉修订：修正第一轮记录底部超出纸面；为罗盘与目标标签留出间距；移开首段标签与灯塔的重叠；提高错误说明字号。

碰撞判断沿航段每不超过 3 个海图单位采样，对可见 SVG 浅滩、海岸及灯塔小岛的填充/边界进行检查。适合本原型的大范围危险区域；不是专业航海模拟或连续物理碰撞系统。
